# 🧤 PhysioGlove

A smart physiotherapy glove for hand rehabilitation using wearable sensors and ESP32. The system monitors finger movements, tracks rehabilitation exercises, and provides real-time data to help patients and physiotherapists monitor recovery progress.

##  Features

- Real-time hand and finger motion tracking
- Wearable and lightweight design
- ESP32-based embedded system
- Sensor data collection and monitoring
- Supports hand rehabilitation exercises
- Easy to expand with IoT and cloud connectivity
- Designed for physiotherapy and research applications

##  Hardware

- ESP32 Development Board
- Flex Sensors
- MPU6050 (Optional)
- Force Sensors (Optional)
- Battery Pack
- Connecting Wires
- Glove

## 💻 Software

- Arduino IDE
- C++
- ESP32 Libraries
- Serial Monitor
- Git & GitHub
